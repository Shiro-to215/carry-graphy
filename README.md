# キャリブレーション・ホモグラフィ統合アプリ

カメラキャリブレーションからホモグラフィ行列の作成までをひとつのウィンドウで行うデスクトップアプリです。既存のキャリブレーションデータを読み込めば、分析を省略してホモグラフィへ進めます。

## セットアップ

Python 3.10以降とTkinterが必要です。プロジェクトフォルダーで統合アプリ用の仮想環境を作成し、依存パッケージをインストールしてください。

```bash
python3 -m venv .venv
source .venv/bin/activate
(./.venv/bin/)python -m pip install -r requirements.txt
```

Linuxでは、PythonのTkinterパッケージが別途必要な場合があります（Ubuntu系では `python3-tk`）。

## 起動

```bash
(./.venv/bin/)python integrated_app.py
```

Windowsでは `start_gui.bat` をダブルクリックしても起動できます。初回は `.venv` の作成と依存パッケージのインストールを自動で行い、以降はコンソールを出さずにGUIだけを起動します。

`cv2` が見つからない場合は、起動に使ったPython環境にOpenCVが入っていません。セットアップと起動で同じ仮想環境のPythonを使ってください。

## 操作の流れ

画面左側のサイドバーで現在のステップと完了状況を確認できます。完了済みのステップはクリックしていつでも戻れます。また、入力した設定値や最後に選んだフォルダは自動で記憶され、次回起動時に復元されます。

1. **ボード作成（任意）**: 最初の画面では、必要ならChArUcoボード画像を作成します。ボード作成は任意です。マス数・長さ・辞書は後のキャリブレーション設定にも引き継がれます。
2. **キャリブレーション**: 動画を解析するか、既存データを読み込むか選びます。動画やNPZ/NPYファイルは入力欄へ直接ドラッグ＆ドロップできます。既存データを使う場合は「既存のカメラ行列ファイル」にNPYまたはNPZをドロップするか［参照］から選択します。統合アプリが出力するNPZには `camera_matrix`、`distortion_coefficients`、`image_size`、`rmse` が含まれ、NPZ単体で読み込めます。これらが不足する旧形式NPZや、カメラ行列だけのNPYは、従来どおり対応JSONが必要です。
3. **動画解析の実行**: 動画を解析する場合は、ChArUcoボードを撮影した動画を指定して［キャリブレーションを開始］を押します。完了するとトースト通知とともに結果を引き継いでホモグラフィ設定画面に進みます。
4. **ホモグラフィ設定**: 基準画像と平面の実寸（幅・高さ）を指定して四隅の選択へ進むか、既存のホモグラフィNPY/NPZを読み込んで完了画面へ進めます。統合アプリが出力するNPYには `homography_matrix`（3×3浮動小数点行列）と `metadata_json`（設定情報を格納した文字列）が含まれ、単体で完結します。従来の3×3行列だけのNPYと、`homography_matrix`、`homography`、`H`、`matrix` のいずれかのキーを含むNPZ（または行列配列を1つだけ含むNPZ）も読み込めます。
5. **解像度の基準選択**: 基準画像とキャリブレーション時の解像度が異なる場合は、どちらの解像度を座標基準にするかカードで選択します。基準画像をキャリブレーション解像度へリサイズする方法と、カメラ行列を基準画像解像度へスケーリングする方法があります。後者は同じカメラ・画角で解像度だけを変更した画像を前提とします。
6. **四隅の選択とドラッグ微調整**: 四隅は「左下 → 右下 → 右上 → 左上」の順にクリックします。**一度打った点はドラッグ＆ドロップで何度でも位置を微調整できます。** カーソル周辺を拡大表示する「拡大ルーペ」で精密に位置合わせでき、ホイールまたは拡大・縮小ボタンでズーム、右ボタンドラッグ（または `Space`＋ドラッグ／中央ボタンドラッグ）で画像を移動、`Ctrl+Z` で1点戻せます。

## ファイル構成

- `start_gui.bat`: Windows 用ワンクリック起動スクリプト（初回は `.venv` 作成と依存パッケージ導入を自動実行）
- `integrated_app.py`: アプリのエントリーポイント（GUI起動および `--calibration-worker` サブプロセス実行）
- `carry_graphy/core/`: 解析・計算・入出力ロジック（GUI非依存）
  - `calibration.py`: ChArUco 動画キャリブレーションエンジン
  - `calibration_io.py`: キャリブレーション NPZ/NPY/JSON の読込・検証・TXT出力
  - `board.py`: ChArUco ボード画像の生成・保存
  - `homography.py`: 解像度合わせ・ホモグラフィ計算・メタデータ内包NPY/TXT出力
  - `settings.py`: 設定値・使用フォルダ・ウィンドウサイズの自動保存
- `carry_graphy/ui/`: CustomTkinter ベースのモダンUI
  - `theme.py` / `widgets.py`: カラートークン・フォント・カード・D&D対応パス入力・トースト通知・サイドバー
  - `point_canvas.py`: 四隅のドラッグ移動と拡大ルーペを備えた画像キャンバス
  - `pages/`: 各ステップ画面（ボード作成 / キャリブレーション / ホモグラフィ設定 / 四隅選択 / 完了）

ボード画像は既定で `統合結果/charuco_board.png` に保存されます。印刷時は「用紙サイズに合わせる」をオフにして、実際のサイズ（100%）で印刷してください。既定の解像度は300 dpiです。

その他の結果も既定で `統合結果` フォルダーに保存されます。キャリブレーション結果は `calibration/calibration.npz` と、解像度・再投影誤差・カメラマトリックス・歪み定数を記載した `calibration/calibration_summary.txt` です。NPZにはホモグラフィ計算に必要な値と再投影誤差を保存します。ホモグラフィ結果は行列と設定情報を内包した `homography_matrix.npy` と、行列・変換条件・座標対応・キャリブレーション情報を読める形で記載した `homography_matrix.txt` です。ホモグラフィ用JSONは出力しません。画面から保存先を変更できます。

ホモグラフィNPYには、選択した解像度の基準、適用倍率、処理に使ったカメラ行列、歪み定数、四隅の座標、平面サイズ、座標系を記録します。TXTにも内容を確認できる形で出力します。キャリブレーション時と基準画像の撮影範囲やカメラが異なる場合、解像度を合わせるだけでは正しい補正値になりません。

キャリブレーションの解析エンジン、ChArUcoボード作成、ホモグラフィ作成は統合アプリ内で実行します。
